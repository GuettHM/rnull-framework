Real arithmetic with a null identity element

Causal Transparency Algebra extends the real numbers with one element, ∅, meaning that no value was supplied. It is distinct from a measured zero, and it is the identity of both addition and multiplication. Set an operand to ∅ below and watch what each operator does with it.

Research prototype. This page is a JavaScript port for exploration; the Python package rnull is the reference implementation, and every number in Measured results comes from the repository's benchmark scripts.

Operators

A value is a pair: a number and a flag saying whether it is ∅. A hatched cell is ∅; a plain 0 is a real, measured zero.

Operation tables

Rows are the left operand, columns the right one; x and y stand for non-zero real numbers.

Structure

The fusion product ⊗ does not distribute over ⊕, and the gap is exactly a whenever b or c is ∅. The absorbing product ⊙ does distribute, which makes (ℝ∅, ⊕, ⊙) a commutative semiring.

  • (ℝ∅, ⊕) and (ℝ∅, ⊗) are commutative monoids with the same identity ∅. There are no additive inverses: x ⊖ x is 0, not ∅.
  • For real a: (a⊗b ⊕ a⊗c) ⊖ a⊗(b⊕c) equals a if b or c is ∅, and 0 otherwise. The detector χ∅ is the case a = 1, b = 0.
  • χ∅ agrees with the mask for every finite real number. For ±∞ it returns NaN, so the software reads the mask.
  • ▷ is an action of the monoid (ℝ∅, ⊗) on (ℝ∅, ⊕): a null weight acts as the weight 1. It is a pass-through, not pruning.

Proofs are in the technical note; the same laws are checked by tests/test_algebra.py and, for this page's port, under Consistency checks.

Linear layer

One neuron, eight inputs: y = ⊕ⱼ (wⱼ ⊙ xⱼ) ⊕ b. Select an input to make it ∅. Without rescaling the result is exactly an ordinary layer on the zero-imputed input; what the layer adds is the coverage and an ∅ output when every input is missing.

Product fusion

Multiplying modalities with ⊗ skips a missing one instead of zeroing the product. The value still changes, and the result mask does not record that a factor was dropped, so keep the count of present factors next to it.

Frozen weights

Under AdamW a zero gradient does not freeze a weight: decoupled weight decay and the decaying moment estimate still move it. An update that is ∅ leaves the weight unchanged, bit for bit. That is a masked update, and it gives the same numbers as W[~mask] += dW[~mask].

Six weights with a leftover first-moment estimate, simulated with the AdamW rule and zero gradient. The repository benchmark (10⁵ weights, 500 steps) is listed under Measured results.

MAC cell

A bit-accurate model of hardware/rnull_mac.v: signed integer operands, each with a one-bit null tag. A null operand skips the cycle and the accumulator holds. acc_null separates "nothing accumulated" from a real sum of 0.

Random stream

RTL of the cell, abridged 
module rnull_mac #(parameter WIDTH = 16, parameter GUARD = 8) (
    input  wire                            clk, rst_n, clear_acc,
    input  wire signed [WIDTH-1:0]         w_val, x_val,
    input  wire                            w_null, x_null,
    output reg  signed [2*WIDTH+GUARD-1:0] acc_val,
    output reg                             acc_null, acc_ovf
);
    wire syn_null = w_null | x_null;                 // skip if either operand is null
    wire signed [WIDTH-1:0] gated_w = syn_null ? 0 : w_val;   // operand isolation
    wire signed [WIDTH-1:0] gated_x = syn_null ? 0 : x_val;
    // prod = gated_w * gated_x, sign-extended;  acc_sum = (acc_null ? 0 : acc_val) + prod

    always @(posedge clk or negedge rst_n)
        if (!rst_n || clear_acc) begin acc_val <= 0; acc_null <= 1; acc_ovf <= 0; end
        else if (!syn_null)      begin acc_val <= acc_sum; acc_null <= 0; acc_ovf <= acc_ovf | add_ovf; end
        // else: registers hold
endmodule

The share of skipped cycles is an activity figure. The cell has not been synthesised: there are no area, timing or power results.

Consistency checks
