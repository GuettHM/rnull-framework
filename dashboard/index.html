Tab 03 • Frozen-Weight Drift Under AdamW

Exact Parameter Freezing: W(t+1) = W(t) ⊕ ΔW with ΔW = ∅

With AdamW, a zero gradient does not freeze a weight: decoupled weight decay (−lr·λ·W) and the decaying first-moment estimate still move it, slowly. Giving frozen weights ΔW = ∅ leaves them bit-for-bit unchanged. That is numerically identical to a masked update (W[~mask] += ΔW[~mask]) or to excluding the weights from the optimizer; this tab simply applies the AdamW rule with zero gradient to six frozen weights and shows the difference.

Tab 04 • Behavioural model of `hardware/rnull_mac.v`

MAC Cell with 1-Bit Null Tags & ∅-Bypass

When syn_null = w_null | x_null == 1'b1, the multiplier operands are forced to zero (operand isolation) and the accumulator is not enabled, so Acc(t) = Acc(t-1). This page models the behaviour in floating point; the RTL is fixed-point with guard bits and an overflow flag. The skipped-cycle ratio is an activity figure, not a power measurement.

// hardware/rnull_mac.v (abridged): 1-bit null tags, operand isolation, guard bits
module rnull_mac #(parameter WIDTH = 16, parameter GUARD = 8) (
    input  wire        clk, rst_n, clear_acc, w_null, x_null,
    input  wire signed [WIDTH-1:0] w_val, x_val,
    output reg  signed [2*WIDTH+GUARD-1:0] acc_val,
    output reg         acc_null, acc_ovf
);
    wire syn_null = w_null | x_null;                 // synapse skipped if either operand is null
    wire signed [WIDTH-1:0] gated_w = syn_null ? 0 : w_val; // operand isolation
    wire signed [WIDTH-1:0] gated_x = syn_null ? 0 : x_val;
    // prod = gated_w * gated_x, sign-extended; acc_sum = (acc_null ? 0 : acc_val) + prod

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)          begin acc_val <= 0; acc_null <= 1'b1; acc_ovf <= 1'b0; end
        else if (clear_acc) begin acc_val <= 0; acc_null <= 1'b1; acc_ovf <= 1'b0; end
        else if (!syn_null) begin                      // clock enable: update on active synapse only
            acc_val  <= acc_sum;
            acc_null <= 1'b0;
            acc_ovf  <= acc_ovf | add_ovf;
        end                                           // else: registers hold
    end
endmodule
