# Changelog

## 1.1.0 — 2026-11-14

Archived release (DOI 10.5281/zenodo.24215450).

This release makes the project installable and testable, unifies its two
implementations, fixes bugs, and replaces unsupported claims with measured
results. It contains breaking API changes (listed below).

### Fixed

* **Installation.** `pip install -e .` failed ("Multiple top-level packages
  discovered in a flat-layout"). `pyproject.toml` now declares the `rnull`
  package explicitly.
* **Test collection.** `pytest tests/` failed with an `ImportError`:
  `tests/test_axioms_and_nn.py` imported names that `rnull/__init__.py` did not
  export. The package now exports one coherent API and the suite is collected
  and run as a whole.
* **Division by zero** in the NumPy implementation returned the numerator
  (`10 / 0 == 10`). Real/real division now follows IEEE-754; ∅ still absorbs.
* **Mislabelled operator.** `causal_coupling` was documented as the directed
  coupling ▷ but implemented the absorbing product ⊙. Both backends now expose
  `synaptic_mul` (⊙) and `synaptic_skip` (▷) with identical semantics.
* **Null parameters could be resurrected** by an optimiser step (`∅ ⊕ Δ = Δ`).
  Optimisers now leave null parameters null.
* **Hidden payloads** behind the mask could differ between otherwise equal
  values. Payloads are now stored as `0.0` under the mask.
* **`RNullTensor` forced float32.** Floating dtypes are preserved.
* **`RNullLinear` memory use.** The forward pass materialised a
  `[batch, out, in]` tensor; it now uses matrix products.
* **Accumulator overflow in `rnull_mac.v`.** The 32-bit accumulator could
  overflow on the third worst-case product. It now has `GUARD` extra bits and a
  sticky overflow flag.
* **Hardware tests.** The only testbench exercised a different module, printed
  values without checking them, and changed stimulus on the active clock edge.
  Both cells now have self-checking, race-free testbenches.
* **README install command** contained Markdown link syntax inside the code
  block and could not be copied.

### Added

* `normalize="mean"` / `"variance"` for the linear layers, and per-output
  **coverage**, so partial absence is observable and the output scale can be
  controlled.
* `fuse_product`, `present_count`; reductions `sum` / `prod`; scalar coercion;
  `/` on both backends.
* `protected_step` (PyTorch): exact freezing of parameter entries with any
  stock optimiser. `NullAdamW` with per-element step counts (`NullAdam` is kept
  as an alias).
* `RNullMacModel`: bit-accurate Python model of `rnull_mac.v`.
* `benchmarks/run_benchmarks.py` (MAC activity, frozen-weight drift, output
  scale) and `benchmarks/missing_data.py` (comparison with imputation
  baselines on three datasets), with stored results.
* `paper/rnull_technical_note.tex/.pdf`: definitions, proofs, limits.
* Continuous integration: tests with and without PyTorch, Verilog simulation,
  benchmark smoke run.

### Changed (breaking)

* The NumPy class is now `RNullArray` (was `rnull.tensor.RNullTensor`); its
  mask argument is `is_null` (was `m`). `RNullTensor` always refers to the
  PyTorch class.
* NumPy layers are batch-first: inputs have shape `(batch, in_features)`.
* NumPy optimisers take parameter slots (`model.parameters()`) and a matching
  list of gradients (`model.backward(...)`), and also update biases.
* `import rnull` no longer requires PyTorch; the PyTorch names are loaded on
  first use.
* `hardware/null_mac.v` is now `hardware/rnull_skip_cell.v` (module
  `rnull_skip_cell`), with renamed status outputs and a wider accumulator.
* `rnull_mac` has a new `GUARD` parameter, a wider `acc_val` and an `acc_ovf`
  output.

### Claims withdrawn or corrected

| v1.0.1 statement | Status |
| :--- | :--- |
| "12/12 tests passing" | The shipped suite had 4 runnable tests and one file that failed to import. The suite now has 85 test cases across two backends. |
| Benchmark table for 10/50/70/90% sparsity | The script computed only 70%; the round figures were the formula (1−p)². The table is now generated by the script, with spread. |
| "MSE 0.412 for AdamW" | Not produced by any script. Measured drift under AdamW with zero gradient is 3·10⁻⁵ to 1.4·10⁻¹ depending on lr·λ (see README). |
| "500 steps, λ = 0.02" | The script ran 100 steps with a hand-written decay of 0.01. Replaced by an actual AdamW comparison. |
| "Eliminates catastrophic forgetting" | Freezing entries is a masked update; it does not address forgetting by itself. |
| "OOD safety / certified refusal" | The layer flags entirely missing input only. Renamed to all-missing abstention. |
| "100% signal preservation" under sensor dropout | The product changes magnitude when a factor is dropped and the mask does not record it. `present_count` is provided. |
| "Zero-power bypass", "% power saved" | No synthesis or power data exist. The figures are skipped-cycle (activity) ratios. |
| "Bit-exact equivalence" between software and RTL | Software is floating point, RTL is fixed point. A bit-accurate Python model of the RTL is now provided and tested. |
| "Exact polynomial detector χ∅" | Equal to the mask for finite values; NaN for ±inf. The mask is the detector. |
| "Zero-dependency" dashboard, "runs pytest" | The page loads CSS and fonts from CDNs and runs JavaScript checks of its own operator port. Labels corrected. |

### Removed

* The 7-page "Complete Technical Guide" PDF (two diverging copies) and the
  architecture banner, which carried the claims above. They remain available
  in the v1.0.1 tag and Zenodo archive.
* The stub `paper/causal_transparency_algebra.tex`, replaced by the technical
  note.
